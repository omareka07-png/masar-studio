# استوديو مَسار للعمليات والصلاحيات

نموذج أولي يعمل في المتصفح لرسم العمليات المؤسسية بمعيار مبسط من BPMN، وتحديد صلاحيات كل عنصر (منفذ، معتمد، يُستشار، يُبلَّغ، السقف، التفويض)، وتوليد دليل الإجراء وتصديره إلى Word وPDF.

- ملف واحد: `index.html`، بلا خادم ولا قاعدة بيانات.
- البيانات تُحفظ في متصفح كل مستخدم (localStorage)، ويمكن نقلها بحفظ النموذج واستيراده بصيغة JSON.
- المكتبات: docx 8.5.0 لملفات Word، وhtml2pdf.js 0.10.1 لملفات PDF.
