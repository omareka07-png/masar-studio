# استوديو مَسار للعمليات والصلاحيات

نموذج أولي يعمل في المتصفح لرسم العمليات المؤسسية، وتحديد صلاحيات كل عنصر (منفذ، معتمد، يُستشار، يُبلَّغ، السقف، التفويض)، وتوليد دليل الإجراء وتصديره إلى Word وPDF.

## أبرز الخصائص
- رسم بالسحب والإفلات مع حارات لكل دور.
- **رسم الإجراء من الهيكل الوظيفي:** أرفق الهيكل مع الأوصاف (Excel أو Word أو نص)، فتُستخلص المهام وتُصنَّف وتُرتَّب وتُرسم آليًا.
- **منهجية البناء:** 11 مرحلة لبناء الإجراء مع قواعد التصنيف والترتيب والترميز، وتظهر في الدليل المُصدَّر.
- مصفوفة صلاحيات RACI، والتفويض، والإصدارات، وسجل النشاطات.

## التشغيل
ملف واحد `index.html` بلا خادم ولا قاعدة بيانات. البيانات تُحفظ في متصفح كل مستخدم، وتُنقل بحفظ النموذج واستيراده بصيغة JSON.

المكتبات: docx 8.5.0، وhtml2pdf.js 0.10.1، وSheetJS 0.18.5، وmammoth 1.6.0.
