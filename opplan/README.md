# منظومة التخطيط التشغيلي والموازنة

نظام تفاعلي حوّل قالب Excel «الخطة التشغيلية والموازنة السنوية» إلى تطبيق ويب: لوحات متابعة، وخطط جانت أسبوعية، وبوابات للإدارات، وقياس للأداء الاستراتيجي.

## التشغيل

| الطريقة | الملف | البيانات |
| --- | --- | --- |
| نسخة مستقلة | `index.html` (افتحه في المتصفح أو عبر GitHub Pages) | وضع محلي تجريبي: أمثلة تُحفظ في متصفح كل مستخدم |
| نسخة Claude Artifact | تُبنى من `app/src.html` وتُنشر على claude.ai | قاعدة بيانات مشتركة بصلاحيات (مدير، محرر، اطلاع) |

لإعادة البناء بعد تعديل المصدر أو البيانات المرجعية:

```bash
python3 app/build.py          # يحدّث index.html
```

## مكونات النظام

- **اللوحة التنفيذية** بأسلوب Power BI: تصفية متقاطعة، ثلاث صفحات، تغيير نوع أي مخطط وحجمه وترتيبه.
- **الأداء الاستراتيجي**: بطاقة الأداء المتوازن لـ 46 مؤشراً، وخريطة استراتيجية، وإدخال المستهدفات والقيم الربعية واستيرادها من Excel.
- **لوحة المهام** و**مهام اليوم**: عدد المهام وحالة إنجازها خلال اليوم والأسبوع والشهر، مع تسجيل تاريخ الإكمال.
- **كشاف المشاريع وبطاقة المشروع**: خطوات تنفيذ بمخطط جانت على 52 أسبوعاً، و**بناء الخطة من نص** يوزّع الخطوات والمدد والتكاليف تلقائياً.
- **بوابات الإدارات**: رابط خاص لكل إدارة لتحديث إنجاز مشاريعها.
- **الحوكمة**: سجل تعديلات (من، متى، قبل وبعد)، وحذف منطقي واستعادة، ومسميات قابلة للتعديل.
- **المظهر**: فاتح وداكن، ست لوحات ألوان مختبرة لعمى الألوان، وتدرجات، ووضع زجاجي، وعرض بملء الشاشة.

## هيكل المجلد

```
opplan/
├── index.html          النسخة المستقلة المبنية
├── app/
│   ├── src.html        مصدر الواجهة (HTML + CSS + JavaScript)
│   └── build.py        يحقن البيانات المرجعية ويبني الصفحة
├── etl/etl.py          تنظيف ملف Excel الأصلي وتطبيعه وتقرير جودته
├── data/
│   ├── master.json     المنظورات والأهداف والمؤشرات والإدارات
│   └── quality_report.json  22 ملاحظة على الملف الأصلي
└── db/schema.sql       مخطط PostgreSQL 16 للمرحلة الثانية (مختبر)
```

## ETL

```bash
python3 -I etl/etl.py <ملف_الخطة.xlsx> data/
```

يقرأ الأوراق الأربع (DATA، كشاف الأهداف والمؤشرات، كشاف المشاريع، مشروع)، ويطبّع الرموز والنصوص، ويُخرج `master.json` و`quality_report.json`.

## المكتبات

Chart.js 4.4.1، وSheetJS 0.18.5، وخطا IBM Plex Sans Arabic وNoto Kufi Arabic من Google Fonts.
